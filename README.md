# 🎯 Englishawy v3 — تحديد الخطوط الإنجليزية من الصور بالذكاء الاصطناعي (محلياً)

بوت تليجرام يحدد الخط الإنجليزي المكتوب في أي صورة **محلياً بالكامل** عبر ثلاث مراحل
ذكاء اصطناعي، ويردّ بـ**بطاقة مقارنة بصرية** (اسم الخط + معاينة حيّة للكلمة) مثل مثال
MUQLA — **بدون أي روابط تحميل خطوط** (لا DaFont ولا WhatFontIs ولا سيرفر خارجي).

---

## 🧠 طريقة العمل (كما طُلبت بالضبط)

1. **قراءة الحروف — Tesseract العصبي:**
   يُمرَّر Tesseract (LSTM) على الصورة بعدة معالجات مسبقة (رمادي، تباين، تكبير، حدة،
   Otsu، عتبة تكيفية…) وبعدة أوضاع تقسيم، ثم **تُدمج النتائج بالتصويت** المرجّح بالثقة
   والتكرار ومعقولية اللغة، وأخيراً **تُصحَّح الكلمات بقاموس** إنجليزي ضخم (wordfreq +
   أقرب مسافة تحرير) مع الحفاظ على حالة الأحرف.

2. **مطابقة الأشكال — Google Fonts:**
   يُرسم النص المقروء بكل خط من مكتبة Google المحلية (حتى ~1800 خط)، ويُقارن بالصورة
   المرجعية من حيث: **شكل الحروف** (IoU ناعم + تشابه حواف Chamfer)، **سُمك الخط**
   (distance transform)، **نسبة العرض للارتفاع**، وإيقاع الحروف (projection profiles).

3. **إعادة الترتيب العصبي — DINOv2:**
   نموذج الرؤية DINOv2 (ViT-S/14 بصيغة ONNX على CPU) يحسب بصمة 384 بُعد للصورة ولكل
   معاينة مرشحة، ثم **يعيد ترتيب أفضل 30 مرشحاً** بمزج التشابه العصبي مع الدرجة الشكلية.

النتيجة: صورة PNG واحدة فيها القص الأصلي + أفضل 5 خطوط، كل صف بالرقم واسم الخط ومعاينة
حيّة للكلمة مرسومة بالخط نفسه (أو `Preview unavailable` عند تعذّر الرسم).

## 📦 بنية المشروع

```text
Englishawy/
├── bot.py                # بوت تليجرام: استقبال صورة → بطاقة مقارنة (بدون روابط)
├── pipeline.py           # ربط المراحل الثلاث وإخراج البطاقة
├── preprocessor.py       # عزل النص + توليد معالجات متعددة للتصويت
├── ocr_engine.py         # Tesseract + تصويت + تصحيح قاموسي
├── font_matcher.py       # رسم النص بمكتبة Google ومقارنة الأشكال
├── neural_reranker.py    # إعادة الترتيب بنموذج DINOv2 (ONNX)
├── comparison_card.py    # رسم بطاقة المقارنة البصرية (مثل MUQLA)
├── setup_assets.py       # تنزيل النماذج والخطوط مرة واحدة إلى الكاش
├── identify_cli.py       # تجربة المحرك من سطر الأوامر بدون تليجرام
├── font_manifest.json    # فهرس خطوط Google (الاسم/الفئة/مصدر التنزيل)
├── requirements.txt      # المكتبات
├── .env.example          # نموذج الإعدادات
└── .gitignore            # يستثني الكاش الثقيل (.cache/ النماذج والخطوط)
```

> الأصول الثقيلة (بيانات Tesseract، نموذج DINOv2، ملفات TTF) **لا تُرفع إلى git**؛
> تُنزَّل مرة واحدة إلى `.cache/englishawy/` عبر `setup_assets.py`.

## 🚀 التشغيل السريع

```bash
# 1) بيئة افتراضية + مكتبات
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt

# 2) تنزيل الأصول مرة واحدة (Tesseract data + DINOv2 + خطوط Google)
python setup_assets.py --workers 20
#   لتخفيف المكتبة:  python setup_assets.py --limit 940

# 3) إعداد التوكن
cp .env.example .env      # ضع TELEGRAM_BOT_TOKEN من @BotFather

# 4) تشغيل البوت
python bot.py
```

### تجربة بدون تليجرام
```bash
python identify_cli.py path/to/image.png --out card.png
python identify_cli.py image.jpg --text "Question" --top 5
```

## ⚙️ الإعدادات (.env)

| المتغير | الافتراضي | الوظيفة |
|---|---|---|
| `TELEGRAM_BOT_TOKEN` | — | توكن البوت (مطلوب) |
| `MAX_RESULTS` | `5` | عدد الخطوط في البطاقة |
| `RERANK_CANDIDATES` | `30` | عدد المرشحين لإعادة ترتيب DINOv2 |
| `FONT_LIMIT` | `0` | حدّ الخطوط المفحوصة (0 = كل المكتبة) |
| `DINOV2_THREADS` | `4` | خيوط المعالج لنموذج DINOv2 |
| `ENGLISHAWY_CACHE` | `.cache/englishawy` | مجلد الكاش |
| `DINOV2_ONNX_PATH` / `TESSDATA_PREFIX` | — | مسارات بديل اختيارية |

## 💡 ملاحظات دقة

- قصّ الصورة على الكلمة/الجملة الإنجليزية فقط لأعلى دقة.
- لو قرأ الـOCR الكلمة خطأ: اضغط **تصحيح النص يدوياً** واكتبها، أو أرسل الصورة ومعها
  تعليق بالكلمة الصحيحة (يُستخدم كنص موثوق ويتجاوز الـOCR).
- أزرار **عكس الخلفية** و**العزل الثنائي** تعيد التحليل للخلفيات الداكنة/الملونة.
- التحقق الداخلي: على عينات مولّدة من خطوط معروفةحقق المحرك **8/8 إصابة في المركز الأول**
  (Playfair, Roboto, Pacifico, Bebas Neue, Great Vibes, Pinyon Script, Lobster, Montserrat)،
  وعلى صور JPEG منخفضة الجودة ظلّت الخطوط الصحيحة ضمن أفضل 3.
