# 🎯 بوت تحديد الخطوط الإنجليزية من الصور — Englishawy v2.4

النسخة المطورة بالكامل من مشروع [Englishawy](https://github.com/mohammedsabryalfiqi/Englishawy.git)، المصممة لتعمل بدقة عالية جداً مثل **MyFonts WhatTheFont** و **WhatFontIs** مع دعم **التخزين الداخلي للخطوط على سيرفر خارجي** بروابط تحميل مباشرة.

---

## 🚀 ما الذي تم إصلاحه وتطويره في الإصدار الثاني (v2.4)؟

1. **وحدة المعالجة البصرية المسبقة للصور (`preprocessor.py`):**
   - في الإصدار الأول كانت الصور ذات الخلفيات الداكنة أو التباين الضعيف تفشل في الكشف؛ الآن يقوم البوت تلقائياً بفحص سطوع الخلفية وعكس الألوان إذا لزم الأمر، وقص الهوامش الفارغة حول الكلمة (`Auto-Crop ROI`)، وزيادة حدة الحروف قبل التحليل.
2. **التخزين الداخلي للخطوط على سيرفر خارجي (`external_vault.py` + `fonts_vault.json`):**
   - فهرس متكامل للخطوط مع بصمتها الهندسية ذات الـ 8 أبعاد (`8D Glyph Vector`) وروابط التحميل المباشرة لملفات الخطوط (`.ttf` / `.otf`) المرفوعة على سيرفرك الخارجي.
3. **تطبيع أسماء الخطوط والكاش المحلي السريع (`dafont.py`):**
   - يعالج مشكلة إرجاع WhatFontIs لأسماء تحتوي على بادئات مسابك مثل `NMY_Abril-Fatface Regular` والتي كانت تفشل في بحث DaFont، مع تخزين النتائج في قاعدة بيانات محلية (`dafont_cache.sqlite3`).
4. **أزرار تفاعلية ذكية داخل تليجرام (`bot.py`):**
   - أزرار أسفل كل رد لإعادة التحليل بحساسية فائقة (`NOTTEXTBOXSDETECTION=1`) أو عكس ألوان الخلفية أو تطبيق العزل الثنائي الحاد (`Binarization`) بضغطة واحدة بدون إعادة إرسال الصورة.
   - دعم استقبال الصور العادية (`Photo`) وملفات الصور عالية الدقة (`Document`).

## 📦 بنية ملفات المشروع المطور

```text
Englishawy/
├── bot.py               # منطق بوت تليجرام المطور + الأزرار التفاعلية لإعادة التحليل
├── preprocessor.py      # معالجة الصور المسبقة وعزل الحروف واستخراج البصمة 8D Vector
├── external_vault.py    # إدارة مستودع الخطوط الداخلي/السيرفر الخارجي والمطابقة الهجينة
├── fonts_vault.json     # قاعدة بيانات الخطوط المفهرسة مع روابط التحميل من السيرفر الخارجي
├── whatfontis.py        # الاتصال المزدوج بـ WhatFontIs API v2 مع Fallback تلقائي
├── dafont.py            # تطبيع أسماء الخطوط + البحث في DaFont + كاش SQLite محلي
├── requirements.txt     # المكتبات المطلوبة (تتضمن Pillow للمعالجة البصرية)
├── .env.example         # نموذج ملف الإعدادات
├── push_to_github.sh    # سكربت رفع التحديثات إلى مستودع GitHub مباشرة
└── README.md            # التوثيق الكامل
```

## ⚙️ طريقة التشغيل السريع

```bash
# 1. تثبيت المكتبات
pip install -r requirements.txt

# 2. إعداد ملف البيئة
cp .env.example .env
# ضع TELEGRAM_BOT_TOKEN و WHATFONTIS_API_KEY داخل .env

# 3. تشغيل البوت
python bot.py
```
