# Englishawy — دليل التشغيل والتعديلات الحالية

## التشغيل بـ Polling (الوضع الافتراضي)

البوت يستقبل الصور والأزرار عبر Telegram long polling. لا يحتاج رابط عام أو سر Webhook.

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt -r requirements-dev.txt
cp .env.example .env
python setup_assets.py --workers 16
python bot.py
```

ضع القيم الحقيقية في `.env` محلياً أو في Secrets على الاستضافة، ولا ترفعها إلى Git:

```dotenv
TELEGRAM_BOT_TOKEN=توكن_BotFather
TELEGRAM_MODE=polling
OWNER_TELEGRAM_ID=5231453921
ADMIN_TELEGRAM_IDS=
WHATFONTIS_API_KEY=مفتاح_WhatFontIs
BOT_REPLY_DELAY_SECONDS=20
```

- `ADMIN_TELEGRAM_IDS`: أرقام حسابات المديرين مفصولة بفواصل. اتركها فارغة إذا لا يوجد مديرون.
- `WHATFONTIS_TOKEN`: اسم بديل مقبول للمفتاح؛ استخدم اسماً واحداً فقط.
- WhatFontIs وWhatTheFont خدمتان مختلفتان. مفتاح WhatFontIs يعمل مع `WHATFONTIS_API_KEY`. أما WhatTheFont فيحتاج `MYFONTS_API_KEY` و`WHATTHEFONT_API_URL` الخاصين باشتراك MyFonts؛ لا تضع مفتاح WhatFontIs فيهما.
- عند بدء polling يزيل البوت Webhook القديم تلقائياً ويحتفظ بالرسائل المنتظرة.
- شغّل **عملية واحدة فقط** لكل توكن: إما `python bot.py` أو `python app.py`. تشغيل الاثنتين معاً يسبب `Conflict`.

## على Hugging Face Space

ملف بدء Space هو `app.py`. يشغّل واجهة Gradio ويبدأ polling داخل نفس العملية افتراضياً، ويجهّز الخطوط/النماذج في الخلفية.

1. ارفع تعديلات الكود إلى المستودع المتصل بالـSpace وأعد تشغيله/بناءه.
2. أضف `TELEGRAM_BOT_TOKEN` و`WHATFONTIS_API_KEY` في Secrets.
3. أضف `TELEGRAM_MODE=polling` و`BOT_REPLY_DELAY_SECONDS=20`.
4. أضف أرقام المديرين في `ADMIN_TELEGRAM_IDS` إن وجدوا.
5. اربط Volume بمسار `/data`، ثم اضبط:
   `ENGLISHAWY_DATA=/data/englishawy` و`ENGLISHAWY_PERSISTENT_STORAGE=1`.
6. راقب اللوج: `Telegram polling started`. في تبويب الحالة يجب أن يظهر «متصل عبر Polling».

لا تحتاج `TELEGRAM_WEBHOOK_SECRET` في وضع polling. المسار الاختياري `/telegram/webhook` موجود فقط لمن يختار `TELEGRAM_MODE=webhook` صراحةً ويضبط رابط HTTPS وسراً صالحاً.

إذا ظهر `Conflict`، أوقف النسخة الأخرى التي تستخدم نفس التوكن. إذا ظهر `InvalidToken`، راجع توكن BotFather في Secrets. لا ترسل التوكن أو مفتاح WhatFontIs في المحادثة.

## المعاينة والكلمة المكتوبة

نتيجة التعرف الخارجية اسم خط، وليست بالضرورة ملف خط مثبتاً. لذلك كان الرسم المحلي يفشل ويظهر `Preview unavailable`.

الآن:
- نتائج WhatFontIs تستخدم معاينة النص المخصص من صفحة الخط العامة، فتظهر الكلمة نفسها وليس عينة حروف عامة.
- يتم اكتشاف رابط المعاينة من الصفحة، وتقييد التنزيل بمضيفات WhatFontIs عبر HTTPS، والتحقق من الصورة وحجمها.
- تحفظ المعاينات مؤقتاً في `.cache/englishawy/previews` لتسريع التكرار.
- إذا كان نفس اسم الخط/الوزن موجوداً في المكتبة المحلية، يرسم Pillow الكلمة من ملفه. لا نستبدل خطاً مختلفاً باسم متشابه.
- إذا حجبت الخدمة المعاينة أو لم يتوفر ملف مطابق، تظهر رسالة عدم توفر معاينة لهذا الخط بدلاً من عرض خط آخر مضلل.

## أزرار النتيجة

يوجد زرّان فقط تحت الصورة:

- **✅ صحيحة**: تأكيد النتيجة.
- **❌ خاطئة**: تجاهل نتائج المواقع والبحث تلقائياً في خطوط المالك المرفوعة فقط، باستخدام نفس النص المقروء. لا يبحث هذا الزر في Google Fonts ولا يعيد استدعاء المواقع.

الأزرار ملونة فعلياً: `style=success` للأخضر و`style=danger` للأحمر (Bot API 9.4+ / python-telegram-bot 22.8). نُبقي ✅/❌ كعلامة احتياطية للعملاء القديمة التي تتجاهل اللون.

التعليق تحت الصورة مختصر: اسم أفضل خط ومصدره، وتظهر بقية الأسماء والمعاينات داخل البطاقة.

## وقت الرد

الافتراضي 20 ثانية على الأقل من استلام الصورة حتى عرض النتيجة. وقت البحث والمعاينة الحقيقي يُحسب من هذه المدة؛ إذا انتهى البحث في 3 ثوانٍ يكمل البوت المراجعة حتى 20 ثانية، وإذا استغرق البحث أكثر لا يضيف 20 ثانية أخرى.

هذه مهلة عرض مطلوبة، وليست ادعاءً بأن الانتظار وحده يزيد دقة نموذج التعرف. الانتظار غير حاجب؛ يظل البوت قادراً على استقبال رسائل أخرى. أثناء العمل تظهر حالة فحص ومراجعة مختصرة.

## قائمة الأوامر والصلاحيات

عند بدء البوت يضبط قائمة Telegram الجانبية تلقائياً:

- المستخدم العادي: القائمة فارغة في الخاص والمجموعات.
- المالك في محادثته الخاصة: `/start /help /status /login /owner /fonts /removefont /import_github /jobs`.
- المديرون المحددون في `ADMIN_TELEGRAM_IDS` في محادثاتهم الخاصة: `/start /help /status`.

إخفاء القائمة ليس بديلاً عن التحقق من الصلاحيات. أوامر إضافة/حذف الخطوط وإصدار كود لوحة المالك تظل للمالك فقط وفي محادثة خاصة. صورة المستخدم العادي ما زالت تعمل حتى لو لم يظهر له `/start` في القائمة.

قد يحتفظ تطبيق Telegram بالقائمة القديمة مؤقتاً؛ أقفل المحادثة وافتحها بعد إعادة تشغيل البوت.

## المكتبة والاستيراد

- المالك يرسل TTF/OTF/TTC/WOFF/WOFF2 أو ZIP في محادثته الخاصة.
- للمستودعات الكبيرة: `/import_github https://github.com/OWNER/REPO` أو لصق الرابط مباشرة.
- `/jobs` لمتابعة الاستيراد الخلفي، و`/fonts` لعرض الخطوط و`/removefont ID` للحذف.
- تنزيل ملفات Telegram العادي محدود بـ20MB؛ سحب GitHub يتم من الخادم ولا يخضع لهذا الحد.
- التخزين الدائم يحتاج Volume مربوطاً فعلياً. وجود مجلد قابل للكتابة وحده لا يضمن بقاء الخطوط بعد إعادة التشغيل.

```bash
python -m pytest -q
```

الاختبارات تغطي المعاينة النصية، منع روابط المعاينة غير الموثوقة، مطابقة الاسم/الوزن، زر الخطأ والمكتبة فقط، الأزرار القديمة، قائمة الأوامر، وقت الرد غير الحاجب، التخزين والاستيراد، ومسار Webhook الاختياري.

يلزم اختبار حي بتوكن البوت ومفتاح WhatFontIs الحقيقيين على الاستضافة؛ لا تتضمن المستودع أي مفاتيح سرية.
